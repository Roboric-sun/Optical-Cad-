# Приближение к Geopter

Ориентир — публичный [Geopter](https://github.com/heterophyllus/Geopter), его [редакторы](https://github.com/heterophyllus/Geopter/tree/master/geopter/gui/SystemEditor), [окна анализа](https://github.com/heterophyllus/Geopter/tree/master/geopter/gui/AnalysisDlg) и [типы решений параметров](https://github.com/heterophyllus/Geopter/tree/master/geopter/optical/include/solve). Наличие одинаково названного анализа не доказывает численное совпадение. Непоследовательный режим нашего проекта развивается дополнительно по приложению Д пользователя.

| Возможность | Optical CAD 0.5 | Оставшаяся работа |
|---|---|---|
| Редактор последовательной системы | Радиус, расстояния, материал, диафрагма, коника/A4–A10, позы | Высшие и нечётные асферики, полноценные coordinate breaks |
| Апертура, поля, волны | EPD/f/#, угловые поля X/Y, положительные веса, первичная волна | Другие определения поля и зрачка, виньетирование полей, точная спецификация NA |
| Материалы | SCHOTT, ручной nd/Vd, AGF Sellmeier 1 | Дополнительные формулы дисперсии и поставщики |
| Параксиальный и одиночный луч | EFL/BFL/ABCD, траектория и OPL | Проверка каждого пересечения на независимом эталоне; параксиальные зеркальные схемы |
| Геометрические анализы | Пятно, RMS, T/S ray fan, геометрическая MTF, сферохроматизм, кривизна поля, хроматический фокус | Сходимость по сетке, независимые эталоны многолинзовых систем |
| Волновые анализы | OPD, волновой фронт, скалярные монохроматические FFT PSF/MTF | Корректное преобразование выходного зрачка для сложных схем, общий полихроматический масштаб, сходимость |
| Solves и pickup | Связи радиусов/толщин с множителем и смещением; краевая толщина; общая длина, проверка циклов, сохранение идентичности при вставке/перестановке | Маргинальная высота, pickup кривизны, дополнительные решения и перенос solves из Geopter JSON |
| Файлы примеров Geopter | Подмножество SPH/ASP, angular fields, EPD/FNO | Виньетирование, остальные поля/апертуры и асферики; неподдерживаемое отклоняется явно |
| Python-консоль | C++ API и демонстрационный CLI | Встраивание интерпретатора и контролируемая автоматизация проектов |

Версия 0.4 добавляет собственный редактор функции качества и ограниченную оптимизацию — это развитие рабочего процесса из требований пользователя. Это не утверждение, что данный редактор или алгоритм повторяет реализацию Geopter. Исходный код расчётного ядра Geopter не включён.

Приоритет следующих версий:

1. Расширить solves: маргинальная высота, связи кривизн и импорт метаданных решений Geopter. Базовые связи, краевая толщина, общая длина и проверка зависимостей реализованы в версии 0.5.
2. Определения поля/апертуры и коэффициенты виньетирования, чтобы расширить перенос существующих систем.
3. Численные эталоны Geopter для главных/маргинальных лучей, RMS, OPD и FFT; независимая оценка сходимости.
4. DLS-оптимизация, допуски и компенсаторы; выходной зрачок и полихроматическая дифракция.
5. Дополнительно для непоследовательного режима: стек сред, контакты, пропускающее рассеяние, измеренные источники и CAD-адаптер.

Встроенная оптимизация остаётся локальным координатным поиском. Полная совместимость с Geopter и промышленная точность пока не заявляются.
