# Проверка версии 0.8

Проверено 4 октября 2026 на текущем ARM64 Mac. `optics_physics`: **519** проверок, `optics_gui`: **401** проверки интерфейса и файлов; всего **920**, включая все прежние 753 проверки версии 0.7. Добавлены 77 физических и 90 интерфейсных/файловых проверок. Release и Debug с AddressSanitizer/UndefinedBehaviorSanitizer проходят обе группы CTest; в обоих наборах подтверждены 519/401 проверок. Проверка утечек Qt отключена (`detect_leaks=0`); отсутствие утечек не подтверждалось.

Версия 0.8 прошла [GitHub Actions 37220090789](https://github.com/Roboric-sun/Optical-Cad-/actions/runs/37220090789), C++ код `e0c916a5d9b6048ea95d2d810e387440709d59e6`. Успешны macOS/Qt 6.11.1, Windows/MSVC/Qt 6.8.3 и Linux без Qt. На macOS и Windows прошли обе группы CTest и учебный пример; EFL=68.558709 мм и финальный RMS=26.429473 мкм совпадают. Сформированы оба пакета; macOS CI проверил подпись, локальные зависимости и семь созданных примеров. Последующие изменения отчёта, README и матрицы требований касаются только документации.

Локальный полный ZIP 0.8 распакован вне синхронизируемой папки и проверен: подпись, 25 объектов Mach-O с локальными зависимостями, семь созданных примеров, документы этапа 0.8, оригинальные численные данные Double Gauss и независимый скрипт дублета. Скрипт успешно запускается из распакованного пакета. Ручная проверка на другом пользовательском Windows/Mac не выполнена.

Виньетирование сверяется с независимыми знаковыми числами: (.5,−.8), VUX=.2/VLY=.5 → (.4,−.4); (−.5,.8), VLX=.4/VUY=.25 → (−.3,.6). Проверены обратное преобразование, физическая маска FFT, неподвижный главный луч, физические миллиметры STOP, конечный объект и прицеливание за преломляющей поверхностью. Отрицательные, вырожденные и нечисловые коэффициенты отклоняются по каждой из четырёх сторон.

Для круглого зрачка половинного диаметра скалярная MTF сравнивается с независимой аналитической формулой `2/π × (acos(ρ) − ρ√(1−ρ²))` с допуском .045 на сетке 64. Проверены энергия PSF=1, неизменный физический размер пикселя, меньший частотный срез и симметрия X/Y; асимметричная маска даёт различные срезы. Пятна, волновой фронт, маргинальное решение и оптимизация используют новое поле. Это проверка текущего приближения, а не подтверждение сложных выходных зрачков.

GUI проверяет таблицу семи параметров поля, ввод с точкой/запятой, inline-ошибки, повторное сохранение, формат 5 и запрет маскировки форматами 1–4. Ссылки условий по лучу/функции качества сохраняют идентичность после перестановки; удаление используемой строки отклоняется. Проверены реальная кнопка ленты, пересчёт, undo/redo, отмена и устаревший диалог после замены проекта. Снимки редактора и Double Gauss находятся локально в `artifacts/v0.8/ui`; тесты используют Qt offscreen.

Оригинальный `dbgauss.json` импортируется с 11 физическими поверхностями, STOP=5 (индекс C++), тремя полями и тремя волнами. Все коэффициенты сохраняются, неверные массивы отклоняются. Для каждого поля девять координат зрачка, включая центр и края, трассируются до внутреннего STOP; невязка к заданной преобразованной координате меньше 1e-7 мм. Внешнее поле даёт реальные точки пятна. Радиус апертуры пятой поверхности теперь оценивается по пересечениям (~17.94 мм); прежний минимум EPD/2=25 мм превышал её сферический радиус ~24.23 мм и блокировал импорт. Полная эквивалентность с исполняемым Geopter/Zemax не заявляется.

Предыдущий автономный пакет 0.7 запущен с `vignetted_singlet.optcad`: отказ с кодом 1 и `Unsupported project format / version`. Новое приложение читает форматы 1–5. Шесть прежних примеров не изменились; новый седьмой содержит коэффициенты в формате 5. Учебный пример при R1=70 сохраняет EFL=68.558709 мм и RMS=26.429473 мкм.

[Подробности модели и ограничений](FIELDS_RU.md). Прежние геометрические эталоны, оба режима, исправление выпадающего списка и учебная программа остаются в регрессии. Резервная копия 0.7 — `artifacts/backups/OpticalCAD-v0.7-source.tar.gz`.
