# Интерфейс версии 0.3 и рисунки приложений Г/Д

Внешний вид воссоздан по двум рисункам из DOCX и фотографии, присланной пользователем. Документы задают требования к продукту; красные номера выносок на рисунках являются пояснениями, а не элементами приложения. Готовые рисунки не используются вместо интерактивного интерфейса.

| Часть эталона | Реализация |
|---|---|
| Синяя строка документа | Название приложения, модуля и текущего проекта; сохранение, сворачивание, разворачивание и закрытие |
| Строка вкладок Word | Файл, два режима, Анализ, Оптимизация, Допуски, Библиотеки, Макросы, Визуализация, Управление требованиями; сохранён порядок |
| Лента последовательного режима | Система → Поверхности → Элементы → Материалы → Расчёт → Анализ → Обмен |
| Лента непоследовательного режима | Система → Объекты → Источники → Приёмники → Свойства → Расчёт и анализ → Обмен |
| Размеры и расположение команд | Крупные значки над подписью, малые значки слева от подписи в колонках; названия групп снизу и вертикальные разделители |
| Навигатор | Синяя полоса, поиск, инструменты дерева, столбцы имени/значения/видимости/выбора; узлы с векторными значками |
| Вкладки рабочей области | Схема или 3D-модель, редактор, открытые анализы; закрытие и перемещение вкладок |
| Панель активного вида | Отмена/повтор, масштаб, вписывание, сетка, нижняя панель, стандартный вид, отделение окна; контекстные числовые поля |
| Последовательный режим | Схема сверху, редактор поверхностей снизу справа; навигатор занимает всю левую колонку |
| Столбцы поверхностей | №, тип, комментарий, радиус, толщина, материал, покрытие, полудиаметр, коника, наклон; покрытие и положение открываются двойным щелчком |
| Непоследовательный режим | 3D-сцена сверху, карта детектора с цветовой шкалой и результатами снизу справа |
| Легенды и видовой куб | Поля по цветам; категории прямых/отражённых/рассеянных лучей; щелчок по кубу задаёт вид |
| Строка состояния | Режим, оптические характеристики либо состав сцены, количество лучей, предел сегментов и состояние расчёта |

Расширенное представление таблицы поверхностей включается контекстным меню. Оно сохраняет доступ к отдельным T/R, координатам, углам и коэффициентам A4–A10, не меняя параметры модели при переключении вида.

Иконки — собственная векторная отрисовка в `src/app/office.cpp` с вариантами 16–64 px. Их силуэты и цвета повторяют образцы, однако отдельные оригинальные ресурсы значков отсутствуют. Пиксельное совпадение с исходным комплектом не подтверждено. Метрики шрифта и нативные диалоги могут отличаться между macOS и Windows; лента адаптируется к ширине окна.

В заголовке используется имя Optical CAD: интерфейс является самостоятельным приложением и не объявляется модулем уже подключённого САРУС. Геометрия, параметры и числа на экране относятся к открытой модели; иллюстрационные значения из эталона не подставляются в результаты. Карта показывает радиометрическую облучённость в Вт/мм². Фотометрические люксы и люмены на исходном рисунке требуют отдельной спектральной модели.

В версии 0.3 кнопка «Призма» включена в непоследовательном режиме: создаёт замкнутое треугольное тело с настоящим расчётом. «Аберрации» показывает два графика T/S на общей шкале. Расположение команд ленты сохранено.

Не реализованные расчётные команды видимы на своих местах и отключены: поляризация, среда, призмы в последовательном режиме, CAD, объёмные/поверхностные детекторы, смешанный режим и STEP. Разделы допусков, макросов и управления требованиями также недоступны. Их наличие в ленте не означает готовности соответствующих функций.

Снимки настоящих виджетов Qt находятся в `artifacts/screenshots`: `sequential.png`, `scene.png`, `reference_nonsequential.png` (1920×1080), `compact_nonsequential.png` (1280×800). Они служат визуальной проверкой текущей версии, а не макетами будущего интерфейса.
