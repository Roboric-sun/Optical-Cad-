# Исправления по рецензии тестировщика — Optical CAD 1.1

| Замечание | Изменение |
|---|---|
| Текст виден только в выделенной строке | Явные тёмные цвета текста таблиц, дерева, полей и меню; проверены реально отрисованные невыделенные строки при светлой/тёмной системной палитре |
| Ручной материал | Сохранён существующий редактор; те же правила десятичных разделителей применены к его числовым полям |
| Пересечение продолжений поверхностей блокирует всё | Центральная апертура соосных интерфейсов обрезается по первому общему краю, включая внешнюю оболочку с меньшими внутренними интерфейсами. Замкнутые области рисуются без самопересечений; внешние лучи отсекаются. Непригодный черновик сохраняет геометрический предпросмотр с диагностикой |
| Не найдено открытие примеров | Видимые кнопки Открыть/Примеры/Сохранить на ленте, встроенный выбор примеров, обычное открытие `.optcad` и поддержанного Geopter `.json` |
| Масштаб только по Y | Колесо внутри графика масштабирует обе оси относительно курсора; над осью — только её. Сброс восстанавливает весь диапазон. Это действует в анализах, картах и схеме |
| Точка/запятая | Оба разделителя принимаются в таблицах, дробных spin box, полях/волнах, связях и функции качества; единый вывод с точкой, без разделителей тысяч. JSON и CSV сохраняют формальные правила формата |
| Мелкий текст ленты | 13 px, полужирный; при нехватке ширины — горизонтальная прокрутка вместо уменьшения до 7 px |

Добавлен [глаз Гульстранда № 1](GULLSTRAND_EYE_RU.md): 6 преломляющих поверхностей, STOP, материалы и три волны. Отдельный счётчик над схемой меняет только показываемые лучи; точность анализов задаётся сеткой зрачка.

Обрезка не заменяет произвольный CSG/смешанную трассировку. Контакт/пересечение разных наклонённых объёмов, обход ядра и кривая сетчатка требуют следующих этапов ядра. В пределах нового примера работают схема, пятно, волновой фронт, PSF/MTF, сохранение и повторное открытие.
